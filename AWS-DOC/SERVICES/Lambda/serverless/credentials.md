## Credentials 

Use credentials in sls using `.env`

```.env
AWS_ACCESS_KEY_ID=XXX
AWS_SECRET_ACCESS_KEY=XXX
SERVERLESS_ACCESS_KEY=XXX
USERS_TABLE=users-table-dev

```
> [!NOTE]
> Remember about the `SERVERLESS_ACCESS_KEY`
